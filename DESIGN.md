# Setup terminal

Mode: Operate. User-approved classic terminal wizard, implemented with Textual.
Fixed step rail at left, scrollable task panel at right, persistent navigation below.
Classic terminal appearance: charcoal background, plain text headings, thin line
borders, restrained cyan emphasis and amber errors. One-line actions use reverse
video on keyboard focus; the current step has an arrow marker, separate from focus.
No bright button fills or marketing headline. Keyboard instructions are visible in
the welcome screen and step rail. A compact status strip leaves room for the task.
Installation links use a compact grid. At widths below 88 columns the rail hides;
the step heading and persistent navigation remain visible.
Square borders, no animation beyond the active task indicator. Status words supplement
color. Tab/Shift+Tab move focus, arrows operate lists, Enter activates buttons,
Alt+Left/Right move steps, Ctrl+S saves, Ctrl+Q saves and exits, Escape goes back.
No progress claim until its corresponding check succeeds. External actions have
explicit consent checkboxes; credentials use masked inputs and never enter saved UI state.
